# My To-Do List 📝

A simple and responsive To-Do List web application built using HTML, CSS, and JavaScript.

## 🚀 Features

* Add new tasks
* Add tasks using the Enter key
* Mark tasks as completed
* Delete tasks
* Filter tasks by:

  * All
  * Active
  * Completed
* Task counter
* Empty-list message
* Tasks saved using Local Storage
* Responsive design for mobile and desktop

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Local Storage
* Git & GitHub
